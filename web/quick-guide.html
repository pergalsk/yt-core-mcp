Quick guide

The shortest way from zero to your first working tool call. It takes about 15 minutes, most of it in Google Cloud Console.

  1. Google client
  2. Build
  3. Log in
  4. Connect AI
  5. Try it

You need Node.js 26+ and the Google account that owns your YouTube channel.

1. Create a Google client

  1. Open Google Cloud Console and create a project.
  2. APIs & Services → Library: enable YouTube Data API v3 (and YouTube Analytics API if you want analytics).
  3. Google Auth Platform → Branding / Audience: user type External, add your account as a test user, then Publish app → In production. In Testing mode your login expires every 7 days.
  4. Clients → Create client → Desktop app. Download the JSON file.
  5. Save it as %APPDATA%\yt-core-mcp\client_secret.json (macOS/Linux: ~/.config/yt-core-mcp/client_secret.json).

2. Build

npm ci
npm run build

3. Log in

Run this in a terminal. Your browser opens; sign in and approve.

node dist/bin.js auth

Want captions, comments and analytics too? Add every permission at once:

node dist/bin.js auth --add all

4. Connect your AI assistant

Claude Code (use your own path):

claude mcp add yt-core -- node D:/Projects/yt-core-mcp/dist/bin.js

Other clients: see Connect an MCP client.

5. Try it

Ask your assistant:

  • “Check yt-core auth status.”
  • “List my last 5 live streams.”
  • “Schedule a private live stream for next Sunday 9:00 called Test.”

Before anything risky — deleting, replying to a comment, or making a video public — the assistant has to ask you to confirm.
